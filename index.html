      // HOW TO PLAY

      Everything happens in a pretend terminal. Type commands and press Enter. Type help any time to see what you can do. Tab auto-completes, and ↑/↓ bring back earlier commands.

      Terminal Race

      Everyone breaks into the same server through 5 layers: find a password, decrypt a file, crack a PIN, find a backdoor, then get root. First to root wins. Stuck? Type hint.

      Typing Duel

      Type the command shown, exactly, and press Enter to hit your target's firewall. Streaks hit harder. Tab switches target. Last firewall standing wins.

      Hack & Defend

      Protect your 3 servers while stealing data from everyone else. scan, breach, trace, kill, and patch all cost CPU. Most data after 5 minutes wins.

      Co-op Heist

      Work as a team. Each person sees different clues, so talk in chat. The Infiltrator works the vault, the Analyst reads the files, and the Lookout keeps the alarm down. Crack all 3 stages before the alarm goes off.

      Root Access is a game. None of these commands do anything to real computers.
