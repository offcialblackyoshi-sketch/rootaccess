      // HOW TO PLAY
      
    
      New here? Press Tutorial on the main menu for a 2-minute guided lesson.
      
    
      Everything happens in a pretend terminal. Type commands and press Enter. Type help any time to see what you can do. Tab auto-completes, and ↑/↓ bring back earlier commands.
      
    
      Terminal Race
      
    
      Everyone breaks into the same server through 5 layers: find a password, decrypt a file, crack a PIN, find a backdoor, then get root. First to root wins. Stuck? Type hint. Asking again gives a more specific hint, but it costs you some time.
      
    
      Typing Duel
      
    
      Type the command shown, exactly, and press Enter to hit your target's firewall. Streaks hit harder. Tab switches target. Yellow ★ BONUS commands repair or shield you instead of attacking. Last firewall standing wins.
      
    
      Hack & Defend
      
    
      Protect your 3 servers while stealing data from everyone else. scan, breach, trace, kill, and patch all cost CPU. Most data when time runs out wins.
      
    
      Co-op Heist
      
    
      Work as a team. Each person sees different clues, so talk in chat. The Infiltrator works the vault, the Analyst reads the files, and the Lookout keeps the alarm down. Crack all 3 stages before the alarm goes off.
      
    
      Quick Hacks (easy, no typing)
      
    
      Short mini-games played with the arrow keys, Space/Enter, or the mouse. Each has 5 stages that get harder, and the first player to clear all 5 wins. A mistake locks you out for 3 seconds. Nobody gets knocked out.
      
    
        
      
      • Letter Lock: press Space or Enter when the glowing column shows the next password letter in its middle row.
        • 
      
      • Print Match: pick the parts that appear in the target print, then press Enter.
        • 
      
      • Signal Tune: turn the knobs until your wave sits on the dashed target, then press Enter.
        • 
      
      • Circuit Path: steer the signal through the maze to the exit without bumping walls.
        • 
      
      • Code Memory: watch the cells flash, then repeat them in order.
        • 
      
      • Wire Cut: use the first rule on the card that is true, and cut those wires in order.
        • 
      
      • Port Sweep: close each port while it is lit up. Don't hit dark ones.
        • 
      
      • Bit Flip: flip switches until their values add up to the target, then press Enter.
        • 
      
      • Hack Gauntlet: a different mini-game every stage.
        • 
    
      
    
      Root Access is a game. None of these commands do anything to real computers.
